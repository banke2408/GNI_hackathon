account_tree System Architecture & Data Flow

Edge: each bike runs an ESP32 firmware state machine (LOCKED → UNLOCKING → RIDING → LOCKING) and publishes bike/{id}/telemetry every second.
Offline-first: fixes are appended to a 500-entry flash ring buffer when Wi-Fi/GPS is lost and flushed in order on reconnect.
Rebalancing: a scheduled job compares dock fill vs. predicted demand and emits ranked move suggestions shown on the Rebalance tab.

build Setup Guide

  1. Assemble each bike node using the wiring diagram; mount the servo latch on the frame lock bracket.
  2. Flash firmware via Arduino IDE / PlatformIO; set BIKE_ID, Wi-Fi SSID and MQTT host in config.h.
  3. Start gateway: run Mosquitto on the campus Raspberry Pi and connect it to the backend.
  4. Open this dashboard: python3 -m http.server 8080 then visit localhost:8080.
  5. Register bikes PB-01…PB-05 and place them at the Main Hub dock.

person User Guide

  1. Find a nearby bike on the map (green = available).
  2. Unlock with the app (BLE) or tap your student ID on the bike's NFC reader.
  3. Ride — position streams live; leaving the campus geofence sounds the alert.
  4. Return to any dock and push the latch; the servo locks and the ride ends automatically.
  5. Earn karma by returning bikes to low-stock docks.
